Triple Filter App — v2.1 Privacy-Safe Audit

Master + Lapsed + Resolved • Local processing • Explainable classification • Excel/CSV exports

Privacy: The app reads your selected files in this browser. It does not upload member records to ChatGPT or any server. CSV works fully offline. Excel (.xlsx/.xls) requires a third-party SheetJS script from cdnjs unless already cached; that external script is not bundled in this file. For a strictly offline workflow, save your three input files as CSV first and use CSV export. Check your organization's handling policy before using any external JavaScript library with confidential data.

1. Select the three original files

Supports CSV without internet. Excel needs the external Excel reader. Only the first worksheet in each Excel workbook is read. All original Master columns are preserved in the membership exports.

2. Classification settings

How the categories are determined

Master records with a valid current or future Next Payment Date and Membership Type REGULAR or REGULAR_LIFE are ACTIVE (except when RESOLVED-priority is enabled). Other records found in RESOLVED are RESOLVED; otherwise records found in LAPSED or with an expired date since the cutoff are LAPSED. Dates before the defunct cutoff are DEFUNCT. Missing/invalid dates and unexpected future-dated membership types are REVIEW. Conflicting reference-file matches are flagged. Records sharing one ID are not overwritten; every duplicate is preserved and reported.

When a member has no record in Master but appears in LAPSED or RESOLVED, the audit reports “Not in Master.” No new member is fabricated from reference files.

3. Optional: check specific IDs privately

Only used locally; not saved to browser storage. IDs can be omitted from the exported audit by leaving the full-ID checkbox off.

4. Results and downloads

The complete Excel report contains the original personal information in the membership sheets. The audit CSV includes only masked IDs and non-contact classification details unless you explicitly enable complete IDs. All files download to your computer.
